# Known Issues

These are the known issues in HumTheory 0.1b.

## Note Detection

Note detection can be inconsistent on both macOS and Windows.

This can be more noticeable with:

- background noise
- unstable or breathy vocals
- low-quality microphones
- unusual instruments
- dense audio
- rapidly changing pitches

Pitch detection is an active area of development.

## Windows UI Performance

The Windows version can still feel choppy in certain parts of the interface.

This is primarily a polish and performance issue and will be addressed in future releases.

## Windows/macOS Feature Parity

The Windows and macOS builds do not currently contain exactly the same functionality.

Feature parity will continue to improve as development progresses.

## Reporting a Bug

When reporting an issue, include:

- operating system
- HumTheory version
- what you were doing when the issue happened
- steps to reproduce it
- screenshots or recordings if useful
- relevant audio/file details when an analysis result is incorrect

Please search existing issues before opening a duplicate.
