# Changelog

All notable changes to HumTheory will be documented here.

## [0.1b] - Public Beta

### Added

- Hum to MIDI workflow
- real-time pitch detection
- chord and key analysis
- song analysis
- chord progression generation
- music theory tools
- Circle of Fifths
- guitar tools
- virtual piano
- piano roll
- MIDI workflows
- Windows and macOS builds
- HumTheory website

### Known Issues

- Note detection can be inconsistent on both macOS and Windows.
- The Windows UI can still feel choppy in some areas.
- Windows and macOS do not currently have complete feature parity.
- Some features are still being refined.

### Notes

This is the first public beta of HumTheory.

Feedback, bug reports, and suggestions are welcome as development continues.
